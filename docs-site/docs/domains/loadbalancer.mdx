# Домен Load Balancer

**Load Balancer** распределяет входящий трафик по группе бэкендов. Домен закрывает задачу «один
стабильный адрес на сервис, за которым — меняющийся набор инстансов»: NetworkLoadBalancer держит
VIP и слушателей, TargetGroup описывает набор бэкендов и их health-check, Listener связывает
порт/протокол на балансировщике с целевой группой.

Пакет — `kacho.cloud.loadbalancer.v1`, REST-префикс — `/nlb/v1`.

## NetworkLoadBalancerService

| RPC | REST | Тип |
|---|---|---|
| `Get` | `GET /nlb/v1/networkLoadBalancers/{network_load_balancer_id}` | sync |
| `List` | `GET /nlb/v1/networkLoadBalancers` | sync |
| `Create` | `POST /nlb/v1/networkLoadBalancers` | async |
| `Update` | `PATCH /nlb/v1/networkLoadBalancers/{network_load_balancer_id}` | async |
| `Delete` | `DELETE /nlb/v1/networkLoadBalancers/{network_load_balancer_id}` | async |
| `Start` | `POST /nlb/v1/networkLoadBalancers/{network_load_balancer_id}:start` | async |
| `Stop` | `POST /nlb/v1/networkLoadBalancers/{network_load_balancer_id}:stop` | async |
| `Move` | `POST /nlb/v1/networkLoadBalancers/{network_load_balancer_id}:move` | async |
| `AttachTargetGroup` | `POST /nlb/v1/networkLoadBalancers/{network_load_balancer_id}:attachTargetGroup` | async |
| `DetachTargetGroup` | `POST /nlb/v1/networkLoadBalancers/{network_load_balancer_id}:detachTargetGroup` | async |
| `GetTargetStates` | `GET /nlb/v1/networkLoadBalancers/{network_load_balancer_id}/targetStates` | sync |
| `ListOperations` | `GET /nlb/v1/networkLoadBalancers/{network_load_balancer_id}/operations` | sync |

:::note Парные attach/detach — разная форма запроса
`AttachNetworkLoadBalancerTargetGroupRequest` несёт **вложенный** `attached_target_group { target_group_id }`,
а `DetachNetworkLoadBalancerTargetGroupRequest` — **плоский** `target_group_id`. Форму каждого
запроса сверяйте по `.proto`, а не по симметрии имён.
:::
