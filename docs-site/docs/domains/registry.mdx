# Домен Registry

**Registry** — OCI-реестр артефактов платформы: место, куда пользователь пушит и откуда тянет
контейнерные образы и Helm-чарты. Домен закрывает задачу «своё приватное хранилище образов с
доступом по проектам»: Registry — контейнер верхнего уровня внутри проекта, внутри него живут
репозитории (Repository), а в них — теги (Tag). Data-plane (сам `docker push/pull`) идёт по
стандартному OCI-протоколу с проверкой токена, а control-plane API управляет реестрами и
инвентарём.

Пакет — `kacho.cloud.registry.v1`, REST-префикс — `/registry/v1`.

`ArtifactType` классифицирует содержимое репозитория: `CONTAINER_IMAGE` (docker/OCI образ, включая
multi-arch index), `HELM_CHART` (Helm-чарт), `OTHER` (иной OCI-артефакт), `UNSPECIFIED` (ещё не
классифицирован).

## RegistryService (public)

| RPC | REST | Тип |
|---|---|---|
| `Get` | `GET /registry/v1/registries/{registry_id}` | sync |
| `List` | `GET /registry/v1/registries` | sync |
| `Create` | `POST /registry/v1/registries` | async · Operation |
| `Update` | `PATCH /registry/v1/registries/{registry_id}` | async · Operation |
| `Delete` | `DELETE /registry/v1/registries/{registry_id}` | async · Operation |
| `ListRepositories` | `GET /registry/v1/registries/{registry_id}/repositories` | sync |
| `ListTags` | `GET /registry/v1/registries/{registry_id}/repositories/{repository}/tags` | sync |
| `DeleteTag` | `DELETE /registry/v1/registries/{registry_id}/repositories/{repository}/tags/{tag}` | async · Operation |
| `ListOperations` | `GET /registry/v1/registries/{registry_id}/operations` | sync |

## InternalRegistryService (:9091)

| RPC | Возвращает | Назначение |
|---|---|---|
| `TriggerGarbageCollection` | Operation | Запуск сборки мусора в хранилище реестра |
| `GetRegistryStats` | RegistryStats | Статистика реестра (инфра-данные) |
